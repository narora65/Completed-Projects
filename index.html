PROJECTED NATIONAL CHAMPIONSHIP — MODEL SIMULATION
Every score on this site comes from an XGBoost model trained on 19,800+ FBS box scores (2002–2025), using Elo ratings, rolling scoring form, rest days, and home-field/neutral-site context — never preseason rankings. Win probabilities are calibrated from the model's own historical prediction error. The 2026 season doesn't exist yet, so each week's predicted result is fed back in to project the next week, compounding forward from whatever weeks of the schedule have been entered so far.
