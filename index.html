PROJECTED NATIONAL CHAMPIONSHIP / MODEL SIMULATION
Every score on this site comes from an XGBoost model trained on 19,800+ FBS box scores (2002–2025), using Elo ratings, rolling scoring form, rest days, and home-field/neutral-site context, but never preseason rankings. Each game's result is a random draw from the model's own calibrated uncertainty, not just its safest guess, so occasional upsets and blowouts show up the same way they do in a real season. The 2026 season doesn't exist yet, so each week's result is fed back in to project the next week, compounding forward from whatever weeks of the schedule have been entered so far.
